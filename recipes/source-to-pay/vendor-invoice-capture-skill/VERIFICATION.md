## Safety properties carried over

- Creates **pending** vendor invoices only. Nothing is posted; an AP reviewer still controls the posting decision.
- Duplicate-guarded on vendor + invoice number and on processed message IDs, so a repeat invocation is a no-op.
- Skips invoices whose vendor cannot be confidently matched, recording the reason instead of guessing.
- Handles an empty inbox quietly, so a scheduled invocation does not generate noise.
- Uses `data_create_entities` as its only write action — no update or delete, so it cannot alter pre-existing records.
