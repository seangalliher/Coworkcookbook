# D365 Manage performance and growth Expert

A Dynamics 365 F&SCM expert scoped to the Manage performance and growth area (a level-2 subdomain of Hire to retire) - covers 10 L3 processes.

> ℹ **This is a Cowork custom skill.** Place the contents of the `skill/` folder under `Documents/Cowork/skills/d365-hire-to-retire-manage-performance-and-growth/` in your OneDrive. Cowork auto-discovers custom skills at the start of each conversation.

## Business value

Save time and improve accuracy by giving Cowork a persistent expert context for the target domain - it knows the right entities, the USMF tenant data quirks, and the honest-degrade options before you even open a task.

## How to install

**Option A - One-click ZIP (recommended)**

1. [Download `d365-hire-to-retire-manage-performance-and-growth.zip`](https://github.com/seangalliher/Coworkcookbook/raw/main/recipes/hire-to-retire/d365-hire-to-retire-manage-performance-and-growth/skill/dist/d365-hire-to-retire-manage-performance-and-growth.zip)
2. Extract the archive - you get a folder named `d365-hire-to-retire-manage-performance-and-growth/` containing `SKILL.md`.
3. Drop that folder into your OneDrive at `Documents/Cowork/skills/`.
4. Start a new Cowork conversation - the skill loads automatically.

**Option B - Manual**

1. Open OneDrive in your browser or sync client.
2. Navigate to `/Documents/Cowork/skills/` (create the folder if it doesn't exist).
3. Create a subfolder named `d365-hire-to-retire-manage-performance-and-growth`.
4. Download `skill/SKILL.md` from this recipe and place it inside the subfolder.
5. Start a new Cowork task - the skill is auto-loaded.
